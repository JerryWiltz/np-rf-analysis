# nP 0.49.0 plugin integration

This development update pins the restricted nP plugin bundle generated by upstream commit `ab8bd664e0d49927e752612dd5d2b17f5cecc124`. That commit is one commit after the unchanged `v0.49.0` tag. The copied `vendor/nP.esm.js` has SHA-256:

```text
7fcf9ba94f951253041d6c5f191fcf200fccfdb5c706bb8dbcd93b72c335b05a
```

The restricted bundle excludes `np-misc` and its legacy browser-development helpers. It reports nP `0.49.0` and exposes the DOM-free `schematicSvg()`, `schematicGraph()`, and `schematicTopology()` helpers along with the digital and sampled-transform APIs.

## Worker schematic adapter

User-authored `npjs` still runs only after **Run** is selected and remains inside the disposable worker. The worker replaces the DOM-capable `nP.schematic()` with a controlled adapter that:

1. Generates graph, topology, and SVG text through the DOM-free helpers.
2. Sends only a mount key and SVG text through a new `schematic` protocol message.
3. Limits SVG messages to 1,000,000 characters.
4. Returns the generated text and data to the calling script without exposing the real DOM.

The trusted render child performs a lexical preflight, parses the SVG as XML, permits only the SVG elements and attributes used by nP's canonical schematic library, rejects executable or external-resource features, and reconstructs the SVG with `createElementNS()`, `setAttribute()`, and text nodes. It does not use `innerHTML`. Valid schematic messages are saved and restored with other `npjs` results for note reopening and PDF export.

## Digital state and rendering

The worker namespace exposes nP `0.49.0` waveform, PN, FFT, inverse FFT, modulation, demodulation, and bit-error APIs. Their chart-ready tables continue to use the existing `lineChart()` and `lineTable()` proxies. Worker cleanup now restores `global.tList` and `global.twoTone` in addition to the existing frequency, impedance, and temperature values.

## Educational-content follow-up

The released `0.3.2` lessons and examples were authored for nP `0.0.48`. Several still use the removed positional `mtee()` call and the vault-derived predecessor to nP's current canonical schematic library. The repository root is now the canonical Obsidian test vault. Preserve installed notes from earlier bundles there as tracked historical content; do not silently overwrite or delete them when testing the current plugin.

The current 0.3.3 distributable examples come from the nP REPL and are stored in `nPort-plugin-content/Examples/`. The current build does not include the older vault-authored lesson sequence or static schematic library.
