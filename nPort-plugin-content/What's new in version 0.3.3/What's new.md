# What's new in version 0.3.3

This version refreshes the learning material and brings the plugin's `npjs` workflow closer to the nP REPL.

- Install all 46 nP REPL examples as numbered notes in REPL order under `nPort RF Analysis/Examples`.
- Before **Run**, see checks for JavaScript syntax, suspicious line continuations, accidental comma expressions, and direct calls to unknown nP API names. Warnings include line and column and do not block execution.
- Use the pinned nP `0.49.0` bundle, including worker-safe schematic SVG output and sampled-signal, FFT/inverse FFT, modulation, demodulation, and bit-error APIs.

The nP REPL remains the source of truth for the example list and code. The plugin's copies are for use inside Obsidian and do not require a network connection.
